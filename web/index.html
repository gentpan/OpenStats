读数常驻菜单栏

CPU、GPU、内存、网速、温度、电池，八种显示风格任选，可以分开放也可以合成一个图标，间距按你的习惯调。

一点就看全

点开就是一张完整的面板：三个圆环看负载，两列卡片看电池、磁盘、网络与风扇，再往下是高占用进程与常用工具。

看完还能动手

风扇一键降温或强冷，防休眠选好时长就走开，缓存、日志与卸载残留一次清干净，DNS 一键切换。

八种菜单栏风格

双行文字、圆环、饼图、柱状历史……整体选一种统一套用，也能给单个指标单独指定。

七张详情卡片

CPU、内存、GPU、磁盘、温度、电池、网络，每张卡片顶部同一种版式：一个主数值，三项次要读数。

网络详情与 DNS

本地与公网 IPv4 / IPv6、归属地与 ASN、连接探测的延迟与丢包，一键刷新 DNS 或切换 Cloudflare、Google、腾讯、阿里云。

IP 纯净度检测

CleanIP.io 纯净度评分从 F 到 A+，一眼看出出口 IP 是否被标记为 VPN、代理、Tor、机房或有滥用记录。

风扇调速与防休眠

自动、降温、强冷、自定义风扇；防休眠 1 到 12 小时或一直保持，合盖继续运行，过热或电量过低自动恢复。

GPU、磁盘与电池

GPU 功耗、频率与利用率；磁盘按卷拆开看用户数据与系统占用，SSD 健康与累计写入；电池容量、电压与电流。

安全的清理

缓存、日志、浏览器与开发者缓存先扫描预览再清理，钥匙串、Cookie 与历史记录一律不碰。

卸载应用与启动项

卸载时找出应用留下的缓存、偏好设置、容器与登录项，连同应用移到废纸篓；启动项一览，一键停用。

数据留在本机

指标来自本机内核、IOKit 与 SMC，没有统计上报；账号可选，只用来同步设置。

风扇与防休眠

热的时候让它转，
忙的时候别让它睡

防休眠选一个时长就开启：1、2、4、8、12 小时或一直保持，可以让屏幕常亮，也可以只让系统不睡、屏幕照常关闭。合盖运行在电量过低时自动关闭。

网络与 IP 纯净度

出口在哪、干不干净，

下载、上传与最近 60 秒的流量；连接探测每秒 ping 一次，延迟和丢包一目了然；接口、信号、开机后的累计流量也都在。

公网 IPv4 / IPv6 的归属地、ASN 与运营方，原生 IP、住宅 IP 的标记，以及 CleanIP.io 的纯净度评分。DNS 可以一键切到 Cloudflare、Google、腾讯或阿里云。

清理与卸载

先看清再删，
不该碰的一律不碰

缓存、日志、浏览器与开发者缓存先扫描、逐项预览再清理；正在运行的应用的缓存会跳过，下载目录里的内容先移到废纸篓。

卸载应用时一并找出它留下的缓存、偏好设置、容器、登录项与崩溃报告，共享的目录默认保留。

帮助

常见问题

会不会很耗电？

只显示菜单栏时只采集菜单栏用到的指标，M5 Max 实测约 0.3% CPU、16 MB 内存；锁屏、屏幕休眠和系统睡眠时暂停采样与探测。

辅助工具是做什么的，安全吗？

调风扇、合盖不睡眠、刷新 DNS、修改 DNS 服务器和释放内存需要系统权限，由一个通过 SMAppService 注册的辅助工具完成。它只提供这几个固定操作，不执行任意命令，DNS 地址会再次校验；只接受同一开发团队签名的 OpenStats 调用，应用退出时自动恢复风扇与睡眠设置。

会联网吗？

只有几项可关闭的功能会：打开网络详情时向 Cloudflare 查询一次公网地址（10 分钟内不重复）；连接探测按你设定的间隔 ping 你选择的目标；归属地、ASN 与纯净度评分由这台 Mac 直接向 cleanip.io 查询，只发送公网地址；每天从本站检查一次新版本。账号可选，只用来同步设置；没有统计上报。

为什么不上 App Store？

App Store 的沙盒不允许访问 SMC、读取其他应用的缓存和安装特权辅助工具，而这正是大部分功能。

清理会不会删掉重要文件？

只清理白名单目录中的缓存与日志，钥匙串、密码管理器、VPN、Cookie、历史记录一律不碰；清理前可以展开查看每一项，下载目录中的内容会先移到废纸篓。

怎么安装、卸载？

下载 DMG 后把 OpenStats 拖进“应用程序”；也可以用 Homebrew：brew tap gentpan/tap && brew trust gentpan/tap && brew install --cask openstats（新版 Homebrew 要先信任第三方 tap 才能安装）。卸载时先在“设置 › 辅助工具”里卸载辅助工具，再把应用移到废纸篓；用 Homebrew 安装的执行 brew uninstall --zap --cask openstats。

菜单栏图标的顺序怎么调？

按住 ⌘ 键拖动任意一个图标即可，松开后位置会一直保留，重启也不变。新开启的项目由 macOS 安排初始位置，可能离其他图标较远，拖到一起就好。这是系统自带的功能，对所有菜单栏图标都有效。

支持 Intel Mac 吗？

支持，在上方下载 Intel 版即可，需要 macOS 14 Sonoma 或更高版本。用 Apple 智能解释进程只能在 Apple 芯片上使用；Intel 机型的 CPU 不分性能核与能效核，部分功耗与频率读数也可能不显示。开发主要在 Apple 芯片上进行，Intel 机型遇到风扇或温度读数不对，欢迎到 GitHub 反馈。
