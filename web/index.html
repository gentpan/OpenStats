欢迎使用 OpenStats

Mac 的状态，抬眼就看见

CPU、GPU、内存、网络与温度常驻菜单栏，还能调风扇、防休眠、一键清理。所有数据在本机读取，没有账号与统计上报。

每个指标一个图标，点开就是详情

原生 Swift 编写，只显示菜单栏时约 0.3% CPU、16 MB 内存。

  • 八种菜单栏风格

    双行文字、圆环、饼图、柱状历史……整体选一种统一套用，也能给单个指标单独指定。

  • 单项详情，按需显示

    CPU、内存、网络、GPU、温度各有一个窄弹窗，显示哪些区块由你勾选；另有侧边栏主窗口看全部。

  • 网络详情与 DNS

    本地与公网 IPv4 / IPv6、归属地与 ASN、连接探测格子，一键刷新 DNS 或切换 Cloudflare、Google、腾讯、阿里云。

  • 风扇调速与防休眠

    自动、降温、强冷、自定义风扇；屏幕常亮、合上屏幕继续运行，过热或电量过低时自动恢复。

  • 安全的清理

    缓存、日志、浏览器与开发者缓存先扫描预览再清理，钥匙串、Cookie 与历史记录一律不碰。

  • 数据留在本机

    指标来自本机内核、IOKit 与 SMC，没有账号、没有统计上报；公网 IP 查询与连接探测都可关闭。

菜单栏风格，由你挑

点一下下面的风格，页面顶部菜单栏里的 OpenStats 会立即换成这个样子。

网络，一眼看到底

  • 上下镜像的流量历史，上传绿、下载蓝
  • 连接探测格子：每 1 / 2 / 5 秒 ping 一次，延迟、抖动、丢包一目了然
  • 本地与公网 IPv4 / IPv6、路由器、Wi‑Fi 信号，点一下就拷贝
  • 归属地显示国旗、城市、ASN 与网络运营方
  • 一键刷新 DNS 缓存，一键切换 Cloudflare、Google、腾讯 DNSPod、阿里云，或手动填写
  • 各进程的上传与下载速率

公网 IP 查询与连接探测都可以在设置里关闭。修改 DNS 需要管理员权限。

白底蓝，黑底蓝，一套外观

主窗口、设置和弹窗共用同一底色，侧边栏与标题栏不分栏着色；窗口宽高都能拖动调整。

热了就吹，要跑就别睡

风扇模式作用
自动交还 macOS 温控
降温最低到最高转速之间的 60%
强冷最高转速
自定义滑块自由设定

合盖后继续运行适合下载、渲染和远程连接。使用电池且电量低于下限时会自动关闭，避免在包里过热。

风扇与合盖运行需要安装一次辅助工具。它只提供固定的几个操作，不执行任意命令，应用退出时自动恢复设置。

先看清再清理

  • 应用缓存、日志与崩溃报告
  • Chrome、Edge、Brave、Arc、Firefox、Safari 缓存
  • Xcode 编译缓存、模拟器与 npm 缓存
  • 未完成的下载、安装包、废纸篓
  • 一键刷新 DNS 缓存、释放内存

只处理白名单目录；正在运行的应用会跳过，浏览器需先退出；删除前每一项再校验一次，所有操作写入日志。

数据不出这台 Mac

没有账号，没有统计上报。只有两项可关闭的网络功能会联网。

  • 指标来源内核接口（host_processor_info、host_statistics64、sysctl）、IOKit 与 SMC
  • 账号不需要，也没有
  • 统计上报没有
  • 公网 IP打开网络详情时向 ipinfo.io 查询一次地址、归属地与 ASN，10 分钟内不重复，可关闭
  • 连接探测按设定间隔 ping 你选择的目标，只在显示网络项时运行，可关闭
  • 偏好设置保存在本机，不含个人信息
  • 源代码MIT 开源，全部公开

常见问题

会不会很耗电？

只显示菜单栏时只采集菜单栏用到的指标，M5 Max 实测约 0.3% CPU、16 MB 内存；锁屏、屏幕休眠和系统睡眠时暂停采样与探测。

辅助工具是做什么的，安全吗？

调风扇、合盖不睡眠、刷新 DNS、修改 DNS 服务器和释放内存需要系统权限，由一个通过 SMAppService 注册的辅助工具完成。它只提供这几个固定操作，不执行任意命令，DNS 地址会再次校验；只接受同一开发团队签名的 OpenStats 调用，应用退出时自动恢复风扇与睡眠设置。

会联网吗？

只有两项可关闭的功能会：打开网络详情时向 ipinfo.io 查询一次公网地址、归属地与 ASN（10 分钟内不重复）；连接探测按你设定的间隔 ping 你选择的目标。没有账号，没有统计上报。

为什么不上 App Store？

App Store 的沙盒不允许访问 SMC、读取其他应用的缓存和安装特权辅助工具，而这正是大部分功能。

清理会不会删掉重要文件？

只清理白名单目录中的缓存与日志，钥匙串、密码管理器、VPN、Cookie、历史记录一律不碰；清理前可以展开查看每一项，下载目录中的内容会先移到废纸篓。

支持 Intel Mac 吗？

目前在 Apple Silicon 上开发和测试，Intel 机型的风扇与温度读取尚未验证。
